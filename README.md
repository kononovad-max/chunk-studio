# Chunk Studio

Тренажёр американских фраз для уровня B2–C1: 5–7 новых чанков в день (фразовые глаголы, идиомы, коллокации, речевые шаблоны), 60% деловых и 40% бытовых, с озвучкой, проверкой произношения микрофоном и интервальным повторением.

Приложение работает в браузере и ставится на телефон как обычное приложение (PWA): иконка на экране, полный экран, работа без интернета.

## Установка на телефон (Android)

1. Откройте ссылку приложения в **Chrome**.
2. Нажмите «Установить приложение» на главном экране тренажёра или в меню Chrome ⋮ → «Установить приложение».
3. При первом нажатии «Говорить» разрешите доступ к микрофону.

На ПК (Chrome или Edge) установка такая же: значок установки в адресной строке.

## Синхронизация телефон + ПК

Каждое устройство автоматически получает код синхронизации вида `K7QM-2XPA-9TRB-W4HN`. Чтобы продолжить тот же прогресс на другом устройстве: Настройки → «Подключить по коду». Прогресс объединяется, ничего не теряется. У каждого члена семьи и партнёра свой код.

Синхронизация работает через бесплатную базу Google Firebase. Настройка делается один раз (около 10 минут):

1. Откройте https://console.firebase.google.com → **Create a project** → название `chunk-studio` → Google Analytics можно выключить.
2. **Build → Authentication → Get started → Sign-in method → Anonymous → Enable**.
3. **Build → Firestore Database → Create database** → регион `asia-southeast1 (Singapore)` → режим **Production**.
4. Во вкладке **Rules** базы Firestore замените текст содержимым файла `firestore.rules` из этого репозитория и нажмите **Publish**.
5. **Project settings (шестерёнка) → General → Your apps → значок `</>` (Web)** → название `chunk-studio` → Register app. Скопируйте объект `firebaseConfig`.
6. В **Authentication → Settings → Authorized domains** добавьте `kononovad-max.github.io`.
7. Вставьте скопированный объект в `firebase-config.js` вместо `null`:

```js
window.FIREBASE_CONFIG = {
  apiKey: "...",
  authDomain: "chunk-studio-xxxx.firebaseapp.com",
  projectId: "chunk-studio-xxxx",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

Эти ключи не секретные: в веб-приложениях Firebase они всегда видны в коде страницы. Защиту дают правила из `firestore.rules`.

Бесплатного тарифа (Spark) хватает с большим запасом: на одного ученика приходится несколько десятков записей в день при лимите 20 000.

## Новые фразы

Пакеты фраз лежат в папке `phrases/` и перечислены в `packs.json`. Озвучка лежит в `audio/<id>_p.mp3` (фраза) и `audio/<id>_0..2.mp3` (три примера). Новый пакет появляется у всех после обновления репозитория.

Формат фразы:

```json
{
  "id": "p2_01", "cat": "b", "type": "pv",
  "en": "follow up on", "ru": "вернуться к вопросу",
  "sit": "Ситуация на русском, ответом на которую служит первый пример",
  "ex": ["I'll [follow up on] the dates.", "...", "..."],
  "exru": ["Перевод 1", "Перевод 2", "Перевод 3"],
  "stress": "FOLLOW UP on", "note": "Короткая заметка", "audio": true
}
```

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Приложение целиком |
| `sw.js` | Работа без интернета: кэш приложения и озвучки |
| `manifest.webmanifest`, `icon-*.png` | Установка на экран |
| `firebase-config.js` | Настройки синхронизации (`null` = только на устройстве) |
| `firestore.rules` | Правила доступа к базе Firebase |
| `packs.json`, `phrases/` | Дополнительные пакеты фраз |
| `audio/` | Озвучка стартового курса (60 фраз, 180 примеров) |
